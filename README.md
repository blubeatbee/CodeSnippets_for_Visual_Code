# README

Contains a collection of custom made C# Code Snippets for Visual Studio.

Code Snippets are small, pre-defined code that can be expanded into larger sets of code by pressing TAB twice. This makes them a useful shortcut for writing large amounts of repetitive code.

An example that's included with Visual Studio by default is `cw`, which is a shortcut to the `Console.WriteLine()` method.

For more info about using Code Snippets in Visual Studio, see [Use code snippets in Visual Studio](https://learn.microsoft.com/en-us/visualstudio/ide/code-snippets?view=visualstudio)

## Download Guide

If you prefer downloading the `.snippet` files instead of cloning the repository, here's a
step-by-step guide!

> Note that every IDE and code editor have their own way of handling code snippets, so this might not work for yours.

![Picture of the download ZIP link on Github.](https://github.com/blubeatbee/CodeSnippets_for_Visual_Code/blob/main/images/downloadguide.png?raw=true)

- Click the button labelled "**&lt;&gt; Code 🞃**"
- Click "**Download ZIP**" at the bottom of the pop-up window
- Save the ZIP in folder like **Downloads**, or **Documents**, etc
- Extract the ZIP, and move/copy the `.snippet` files you want into Visual Studio's Code Snippet folder
    - For C#, this folder is located at `~/Documents/Visual Studio %VERSION%/Code Snippets/Visual C#/My Code Snippets/`
- To view if any snippets successfully installed
    - Open Visual Studio
    - Select **Tools** > **Code Snippets Manager** or press (**Ctrl+K**, **Ctrl+B**)
    - In Code Snippets Manager window, select **Language: CSharp**
    - In the folder view below, click **My Code Snippets** folder to expand
        - If the folder does not appear for you, click **Add** and navigate to your **Code Snippet folder** again
    - Now you should be able to see the installed Code Snippets
